# SynapVault AI

Turn every document into trusted, connected intelligence.

SynapVault AI is a production-focused document intelligence platform. Users
will be able to upload documents, ask grounded questions, inspect citations,
generate study resources, compare documents, collaborate in workspaces and
manage their information securely.
